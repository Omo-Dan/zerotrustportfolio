This site. A security-first web application delivered through a pipeline. Every change goes through a pull request and automated checks: secret scanning, linting, type checks, tests, static analysis, dependency scanning and container image scanning. Only the pipeline deploys it, after those checks pass, and it confirms the new version is live. The requirements, threat model and decisions are in the repository.

Built with Python, FastAPI, Docker, GitHub Actions and Render.
