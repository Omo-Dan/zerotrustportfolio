# Security policy

## Reporting a vulnerability
If you think you've found a security problem in this project, please
tell me privately. Use GitHub's private vulnerability reporting: open
the Security tab of this repository and choose "Report a vulnerability".
Please don't open a public issue for it.

A useful report says what you found, how to reproduce it, and what you
think the impact is.

## What to expect
I'll acknowledge your report within a few days and keep you updated
while I look into it. If you'd like credit once it's fixed, say so. This
is a personal project, so I can't offer a bounty.

## Scope
In scope: the code in this repository and the deployed version of this
project.

Out of scope: denial-of-service testing, social engineering, physical
attacks, and the platforms I build on (GitHub, Render, AWS). Please
report issues in those to the vendor.

## Testing in good faith
Test against your own copy of the code where you can. On the live site,
keep to gentle, non-disruptive checks, and don't access or change
anyone else's data.

## Supported versions
Only the latest release is supported.
